# botyara

Учебный HTTP-клиент и сервер на Python. Сервер хранит колбэки и задачи в SQLite,
а клиент получает и выполняет только `whoami`, `ip` и `exit`.

## Как это работает

1. Клиент отправляет известный серверу payload UUID через `POST /checkin`.
2. Сервер создаёт callback UUID для конкретного запуска.
3. Клиент раз в несколько секунд запрашивает свою очередь через `POST /poll`.
4. Сервер возвращает первую задачу этого колбэка.
5. Клиент выполняет разрешённое действие и отправляет результат в `POST /results`.
6. Сервер сохраняет состояние и результат в SQLite.

Один payload можно запустить несколько раз. У запусков будет общий payload UUID,
но разные callback UUID и отдельные очереди задач.

```text
payload
├── callback A ── whoami, exit
└── callback B ── ip, exit
```

## Что нужно

- Windows 10 или Windows 11;
- Python 3.10 или новее;
- PowerShell;
- интернет только во время установки библиотек.

Проверь Python:

```powershell
python --version
```

Если команда не найдена, установи Python и включи пункт добавления Python в `PATH`.

## Установка

Открой папку `botyara` в VS Code, затем открой терминал PowerShell и выполни:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Первая команда создаёт отдельное окружение `.venv`. Вторая устанавливает Flask,
Requests и psutil только в это окружение.

## Запуск

Открой первый терминал и запусти сервер:

```powershell
.\.venv\Scripts\python.exe .\server.py
```

Оставь его работать. В терминале должна появиться строка:

```text
Running on http://127.0.0.1:5000
```

Открой второй терминал и запусти клиента:

```powershell
.\.venv\Scripts\python.exe .\client.py
```

Клиент напечатает свой новый callback UUID и продолжит работать. Не закрывай этот
терминал, пока хочешь отправлять клиенту задачи.

Открой панель в браузере:

```text
http://127.0.0.1:5000/
```

Выбери активный колбэк, команду и нажми **Отправить**. Через 2–3 секунды нажми
**Обновить**, чтобы увидеть результат.

Для проверки нескольких клиентов открой ещё один терминал и ещё раз запусти:

```powershell
.\.venv\Scripts\python.exe .\client.py
```

У двух запусков будут разные callback UUID.

## Команды

- `whoami` — имя пользователя, от которого запущен клиент;
- `ip` — локальные IPv4 и IPv6 сетевых интерфейсов;
- `exit` — отправить результат серверу и завершить выбранного клиента.

## Остановка и повторный запуск

Сервер или клиент можно остановить сочетанием `Ctrl+C` в нужном терминале.

После перезагрузки компьютера сначала снова запусти `server.py`, затем `client.py`.
Каждый новый запуск клиента регистрирует новый колбэк.

При первом запуске сервер автоматически создаёт рядом с кодом файл `server.db`.
Он хранит историю. Удаление этого файла при остановленном сервере создаст новую
пустую базу при следующем запуске.

## Если что-то не работает

**В панели нет активного колбэка**

Проверь, что второй терминал с `client.py` открыт и продолжает работать. Затем
нажми **Обновить** в панели.

**Задача остаётся в ожидании**

Проверь, что она назначена текущему callback UUID. Новый запуск клиента не получает
задачи старого колбэка.

**PowerShell не находит `.venv`**

Убедись, что терминал открыт именно в папке `botyara`, и выполни установку заново.

**Порт 5000 уже занят**

Скорее всего, сервер уже запущен в другом терминале. Найди его и останови через
`Ctrl+C`, затем повтори запуск.

- `server.py` — HTTP-маршруты и веб-интерфейс;

## Основные маршруты

| Метод и адрес | Назначение |
|---|---|
| `GET /ping` | Проверка доступности сервера |
| `POST /checkin` | Регистрация нового запуска |
| `POST /poll` | Получение следующей задачи |
| `POST /results` | Сохранение результата |
| `POST /tasks` | Создание задачи через JSON |
| `GET /state` | Получение состояния в JSON |
| `GET /` | Веб-панель |

## Ограничения

Проект предназначен для локального обучения и слушает только `127.0.0.1`.
Клиент выполняет фиксированный набор действий; произвольной командной строки,
автозапуска, загрузки файлов и скрытого режима нет. Payload UUID служит проверкой
по списку известных значений, но не заменяет полноценную аутентификацию.
